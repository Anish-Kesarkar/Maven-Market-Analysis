# Maven Market Analysis

## 📌 Project Overview

An interactive Power BI business intelligence project analyzing
Maven Market data to understand business performance, sales trends
and key performance indicators.

The project transforms raw business data into an interactive
dashboard designed to support data-driven performance analysis.

---

## 🎯 Project Objective

The objective of this project was to:

- Analyze business and sales performance
- Track key performance indicators
- Identify trends and patterns in the data
- Transform raw data into meaningful visual insights
- Build an interactive dashboard for business analysis

---
